# ふたりの当番表

夫婦で「🍳 夕飯」「🏠 在宅当番」の担当と「🌙 夜不在の日」を共有する、カレンダー形式のシンプルな Web アプリです。

- 担当者ごとに **色 + アイコン（絵文字）** で表示（名前・色・アイコンは ⚙️ 設定から変更可）
- 夕飯は「夫 / 妻 / ふたり / なし」、在宅当番は「夫 / 妻 / なし」、夜不在は2人それぞれ選択
- 画面上部に「今日の担当」をまとめて表示
- メールアドレス + パスワードでログイン
- 2人のスマホ・PC間でリアルタイム同期

## 構成

GitHub Pages は静的ファイルしか配信できないため、ログインとデータ保存には **Firebase**（無料の Spark プランで十分）を使います。

| 役割 | 使うもの |
| --- | --- |
| 画面の配信 | GitHub Pages |
| パスワードログイン | Firebase Authentication（メール/パスワード） |
| データ共有 | Cloud Firestore |

`config.js` が未設定の状態では **デモモード**（データはそのブラウザ内のみに保存、ログインなし）で動くので、まず見た目を確認できます。

## セットアップ手順

### 1. Firebase プロジェクトを作成
1. <https://console.firebase.google.com/> で「プロジェクトを追加」（Google アナリティクスは不要）
2. 左メニュー **構築 > Authentication** →「始める」→ **メール/パスワード** を有効化
3. **Authentication > ユーザー** で「ユーザーを追加」から **2人分のアカウント**（メールアドレスとパスワード）を作成
4. **Authentication > 設定 > ユーザー アクション** で「アカウントの作成（登録）を許可する」のチェックを外すと、第三者が勝手に登録できなくなります（推奨）
5. **構築 > Firestore Database** →「データベースを作成」（ロケーションは `asia-northeast1` 東京など、本番環境モードで OK）

### 2. セキュリティルールを設定
`firestore.rules` のメールアドレス2つを手順1-3で作ったものに書き換え、Firestore の **ルール** タブに貼り付けて「公開」します。
これで2人以外はデータを読み書きできません。

### 3. アプリに Firebase の設定を入れる
1. Firebase コンソールの **プロジェクトの設定（⚙️）> マイアプリ** で「ウェブ（</>）」アプリを追加
2. 表示される `firebaseConfig` の値を `config.js` に貼り付けてコミット

> `apiKey` などは公開されても問題ない値です（アクセス制御はセキュリティルールで行っています）。

### 4. GitHub Pages で公開
1. GitHub のリポジトリ **Settings > Pages**
2. Source: **Deploy from a branch**、Branch: 公開したいブランチ（例 `main`）/ `/(root)` を選んで Save
3. 数分後に `https://<ユーザー名>.github.io/task_table/` で開けます
4. Firebase の **Authentication > 設定 > 承認済みドメイン** に `<ユーザー名>.github.io` を追加

スマホではブラウザの「ホーム画面に追加」をしておくとアプリのように使えます。

## ローカルで確認

```bash
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開きます（ES Modules を使うため `file://` 直開きでは動きません）。
